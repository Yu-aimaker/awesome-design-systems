# Apple Human Interface Guidelines

プラットフォームの約束事。独自ブランドより、ユーザーがすでに知っている操作を優先する。

## 要点

- 明快さ: 1画面の目的は1つ。装飾で階層をごまかさない。
- 敬意: コンテンツが主、クロームは従。
- 深さ: レイヤーは「今どこにいるか」を示すために使う。影の重ねすぎは禁止。
- タッチターゲット 44pt 以上。フォーカスリングを消さない。
- Dynamic Type / Reduce Motion / Contrast を設定として扱う。CSS 変数で追従する。
- SF は Apple 製品向け。Web では Geist + Noto Sans JP を使う。

## AwesomeDS への取り込み

- ボタンの最小高さ 40px（Web）、主要操作は 44px。
- モーダルよりまずインライン。重ねるならフォーカストラップと Esc。
- 動きは 180ms 前後。バウンスで「高級感」を作らない。
