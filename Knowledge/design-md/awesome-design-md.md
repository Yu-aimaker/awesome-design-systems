# awesome-design-md（VoltAgent）

AIエージェント向けの `DESIGN.md` 実例集。公開サイトの見た目を Markdown に落とし、プロジェクトへコピーして「この言語で作れ」と指示するための材料。

## 要点

- Google Stitch の [DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) は、`AGENTS.md`（作り方）と対になる「見た目の仕様」。
- 各ファイルはテーマ、色の役割、書体階層、部品、余白、影、禁止事項、レスポンシブ、エージェント用プロンプトを持つ。
- 2026-09 時点で 70 件超。Linear / Notion / Stripe / Apple など、密度とアクセントの使い方がはっきりした製品が多い。
- 抽出トークンは公開 CSS の観察であり、ブランドの公式許諾ではない。コピーは言語の型を学ぶためで、見た目の盗用ではない。

## AwesomeDS への取り込み

- 1製品 = 1言語。複数ブランドのグラデと丸みを混ぜない。
- 色は「意味のある役割」で持つ。装飾用の第3アクセントは原則持たない。
- プレビュー HTML があること自体が正本の検証方法。ショーケースは同じ役割。
