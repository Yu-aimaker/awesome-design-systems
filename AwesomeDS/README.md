# AwesomeDS

エージェントがそのまま使える正本。ブランドをまだ持たないプロダクトはこれを直接使う。ブランドがある場合は `Plugin/skills/DSCreator` で派生を切る。

このディレクトリが唯一の正。`apps/web` のトークンはここを写す。

## 読む順

1. `DESIGN.md` — Stitch 9節（エージェントの入口）
2. `AGENTS.md` — 実装手順
3. `tokens.json` — reference → semantic → component
4. `principles.md` — 品質4点と思考6軸
5. `preview.html` — トークンの静的プレビュー

## 使わないもの

- Inter を本文の既定にしない（Latin は Geist、日本語は Noto Sans JP）
- 紫グラデ、全面ブラー、中央揃えの空中コピー
- 3つ目のアクセント色
- 16px 以上の全面角丸
- 説明のないアニメーション
