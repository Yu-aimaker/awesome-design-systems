# AwesomeDS

エージェントがそのまま使える正本。ブランドをまだ持たないプロダクトはこれを直接使う。ブランドがある場合は `Plugin/skills/DSCreator` で派生を切る。

このディレクトリが唯一の正。`apps/web` のトークンはここを写す。

## 読む順

1. `principles.md` — 判断の軸
2. `color.md` / `typography.md` / `spacing.md` / `radius.md` / `motion.md`
3. `components.md` — 部品の振る舞い
4. `tokens.json` — 実装が読む数値

## 使わないもの

- Inter / Geist を本文の既定にしない
- 紫グラデ、全面ブラー、中央揃えの空中コピー
- 3つ目のアクセント色
- 16px 以上の全面角丸
- 説明のないアニメーション
