# 原則

正本は **品質4** と **思考6軸**。合計10でも5本柱でもない。混ぜて数えない。

## 品質（4）

| 語 | 判定 |
| --- | --- |
| Useful | その画面で作業が終わるか |
| Intuitive | 次の手が3秒で見つかるか |
| Delightful | 成功の合図が過剰でないか |
| Polished | 余白・型・フォーカスが揃っているか |

## 思考（6）

| 軸 | 問うこと |
| --- | --- |
| Purpose | この面の目的は1文で書けるか |
| Agency | Responsibility。止められるか（stop）、やり直せるか（undo） |
| Simplicity | 部品を足す前にコピーで足りるか |
| Craft | トークンと禁則を守っているか |
| Delight | 結果が変わった瞬間だけ動かすか |
| Long-view | 来週も同じルールで足せるか |

## Pre-Flight（反スロップ）

- 紫グラデを置かない
- Inter を既定にしない
- 偽のダッシュボードスクショを置かない
- 空中のスローガン、ダッシュ連打、比喩を書かない
- 16px 超の全面丸、ガラスを置かない
- Funnel Orange 以外の第3ブランド色を置かない。Funnel は1面に最大1–2

見た目の好みより、人が迷わず手元の作業を終えられるかを先に置く。検証はブラウザ。

## Responsibility

破壊・送信・課金に近い操作は、止める手段（キャンセル、閉じる、戻る）とやり直す手段（undo、下書き、再試行）を同じ面に残す。止められないウィザードは Phase1 で置かない。
