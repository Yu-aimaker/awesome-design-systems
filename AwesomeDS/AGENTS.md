## Rules
- Use semantic tokens only (`primary`, `background`, …). Never hardcode hex in components.
- JA-first typography. `line-break: strict`. Self-host fonts via `next/font`.
- One primary accent (blue). No purple gradients. No Inter-by-default.
- Anti-slop: no fake screenshots, no fluff marketing copy.
- Prefer show-don't-tell: live previews over long prose.
- Plugin is Sir-internal for now; design the canon for future OSS (no product-specific brands).
