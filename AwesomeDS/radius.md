# 角丸

| Token | px | 用途 |
| --- | --- | --- |
| sm | 6 | チップ、バッジ |
| md | 8 | ボタン、入力、小さなカード |
| lg | 12 | 大きなカード、プレビュー枠 |
| full | 9999 | アバターとスイッチのノブだけ |

## なぜこの値か

- 8–12 は指で押す対象に十分丸く、イラスト化しない。
- 16–24 の全面丸は 2025–26 の生成 UI 既定。使わない。
- 入力とボタンの半径を揃える。片方が pill でもう片方が角、は禁止。

## 禁止

- カードだけ 24、ボタンだけ 999 の混在。
- 画像を半径 0、枠を半径 16 で切り出す。
