# 色

紙の地に墨の文字。アクセントは森。銅は警告と補助リンクに限る。

| Token | Hex | 役割 |
| --- | --- | --- |
| `paper` | `#F4EFE6` | ページ地。純白より目が楽 |
| `surface` | `#FFFCF7` | カード・入力の面 |
| `raised` | `#FFFFFF` | モーダルなど一段上げる面 |
| `ink` | `#1C1916` | 本文・見出し |
| `inkMuted` | `#5C564C` | 補助文。本文の代わりにしない |
| `inkSubtle` | `#8A8378` | ラベル、キャプション |
| `line` | `#D9D2C6` | 区切り。影の代わり |
| `accent` | `#1F4D3A` | 決定・進行・成功 |
| `accentHover` | `#16382A` | accent のホバー |
| `accentSoft` | `#DCE8E1` | 選択チップ、成功の地 |
| `copper` | `#B4532A` | 注意、外部リンクの印 |
| `danger` | `#9B2C2C` | 破壊操作とエラー。accent の再利用禁止 |
| `dangerSoft` | `#F3D6D6` | エラー面 |

## なぜこの組み合わせか

- 暖色の紙は長文でも冷たいグレーより疲れにくい（WIRED / Notion 系の観察）。
- 緑系アクセントは進行の意味を借りられる（Duolingo、Mintlify）。紫は 2024–26 の AI サイト既定なので使わない。
- コントラスト: `ink` on `paper` は本文に十分。`inkSubtle` on `paper` はキャプション専用。
- ダークモードは Phase 1 対象外。中途半端な自動反転をしない。

## 禁止

- 背景にグラデを敷く
- カードごとに違うアクセント
- 白 80% オーバーレイのガラス
